# 🚀 Level 2 – Task 1: Job Board

A full-stack job portal connecting candidates and employers.

### Features

- Candidate and employer registration/login
- JWT authentication
- Role-based authorization
- Browse jobs
- Search and filter jobs
- Job details
- Job applications
- Resume upload
- Cover letter submission
- Candidate application tracking
- Employer dashboard
- Create job postings
- Manage job postings
- Delete job postings
- View candidate applications
- Update application status
- Responsive UI
- MongoDB persistence

### Tech Stack

**Frontend**
- React
- Vite
- CSS

**Backend**
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcrypt
- Multer
- Nodemailer
